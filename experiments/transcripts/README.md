# Frozen transcripts

Store one raw, unedited transcript per official run here, using names such as
`run-01.raw.txt`.  Save the response before extracting code into
`candidates/run-XX/`; record its SHA-256 in the candidate README and metadata.

Do not overwrite a transcript.  A corrected export is a new file with a dated
suffix and a decision-log entry explaining the protocol deviation.
